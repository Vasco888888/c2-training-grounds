## Features

- **Exam conditions**: the stopwatch starts by itself, and a test can't be paused, saved halfway or resumed. Leave it and the attempt is gone.
- **Instant scoring** with a full explanation for every question, showing why the answer is right and why the other options fail.
- **Official-style marking in Part 4**: each answer is split into two parts worth one mark each, as in the real exam.
- **British English** throughout, with US and UK spellings both accepted in typed answers.
- **Highlighting and notes** on the text while you work.
- **History** of every attempt, with a backup you can export and import.
- **Writing practice** with a word counter against the target range, and a ready-made prompt for getting your answer assessed.

| 6 | Gapped text | 3 |
| 7 | Multiple matching | 3 |
| W1 | Writing: essay | 4 |

All texts and questions are original and written at C2 level.

## Getting started

1. Download or clone the repository.
2. Open `index.html` in any modern browser.

Your results are stored in the browser (localStorage), so use **History → Export backup** now and then to keep a copy.

## Built with

Plain HTML, CSS and JavaScript, with no build step and no dependencies.
